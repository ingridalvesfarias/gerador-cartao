# 🃏 CardForge - Gerador Interativo de Cartão de Visita

Um gerador de cartões de visita moderno e responsivo que permite a personalização em tempo real. Este projeto demonstra habilidades em manipulação dinâmica do DOM, estilização avançada com CSS e funcionalidades de exportação nativas do navegador.

## 🚀 Funcionalidades
- **Live Preview:** Veja as alterações de texto e cor instantaneamente enquanto digita.
- **Personalização de Cores:** Seletores dinâmicos para a cor de destaque (nome/detalhes) e cor de fundo do cartão.
- **Design Dark Mode:** Interface elegante e focada na experiência do usuário (UX).
- **Exportação para PDF:** Funcionalidade integrada para salvar o cartão isoladamente usando a API de impressão do navegador.
- **Responsividade:** Layout adaptável para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica para acessibilidade e SEO.
- **CSS3:** - Flexbox e CSS Grid para o layout.
  - Variáveis CSS (Custom Properties) para gerenciamento de cores.
  - Google Fonts para uma tipografia refinada (*Playfair Display* e *Poppins*).
- **JavaScript (Vanilla):** - Manipulação de eventos em tempo real (`input`).
  - Lógica de atualização dinâmica do DOM.
  - Integração com a Window Print API para exportação de arquivos.
